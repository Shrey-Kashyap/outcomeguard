## Project description

**OutcomeGuard — monitor business commitments across domains.**

OutcomeGuard detects missing business outcomes even when technical systems appear healthy. An operator defines a trigger, required outcome evidence, and deadline; the application correlates incoming events, evaluates the rule deterministically, opens an explainable incident, and verifies recovery from stored evidence. Commerce, event registration, and HR offboarding demonstrate the same generic engine. The runnable MVP uses ASP.NET Core, React, and SQLite.
